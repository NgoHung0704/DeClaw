# DeClaw Atlas

Calm technical atlas for first-time contributors. White panels on a pale sage dotted canvas, forest-green actions, restrained violet for safety and blue for runtime dependencies. Desktop uses a persistent sidebar; mobile uses four navigation tabs and a card companion to the diagram.

Typography: Manrope headings, DM Sans prose, system monospace for code. Semantic tokens, dark theme, visible keyboard focus, native modal dialogs, and reduced-motion support. English default; French and Vietnamese have authored translations.

Graph semantics: modules within the Python process must be distinguished from separate local processes and stores. Planned gateway / desktop / shell sandbox must remain visibly marked as unimplemented. Every node drills into responsibility, input/output, internal stages, source files and contracts. Data journeys are explanatory simulations.
